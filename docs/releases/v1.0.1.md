# Moyai v1.0.1 リリースノート

公開予定日: 2026-08-28

## 概要

Moyai v1の利用者向けドキュメントを整備した修正版です。製品機能とデータ形式にv1.0.0からの変更はありません。

## 変更内容

- ルートREADMEを追加
- インストール、CLI、MCP、Provider認証、Build・Release・Deployの利用ガイドを追加
- 配布物のSHA-256検証手順を追加
- v1.0.0リリースノートを追加
- 設定リファレンスへrepository、authentication、lifecycleコマンドを追記

## 配布物

- `Moyai-1.0.1-x64.msi`
- `Moyai-1.0.1-x64.msi.sha256`

リリースページ: https://github.com/katsushoe/Moyai/releases/tag/v1.0.1

## 互換性

- v1.0.0のSQLiteデータベースをそのまま使用できます。
- インストール先は引き続き`C:\Moyai`です。
- Windows x64、CLI、MCP、Provider設定の要件に変更はありません。
