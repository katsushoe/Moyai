# Moyai v1.0.0 リリースノート

公開日: 2026-08-28

## 概要

Moyai最初の正式リリースです。プロジェクトと作業項目のSQLite管理、CLI、Streamable HTTP MCPサーバー、Provider routing、サービス間認証、Build・Release・Deploy lifecycleを提供します。

## 主な機能

- ProjectとWorkItemの作成、参照、更新、論理削除、状態遷移
- revisionによる楽観的同時実行制御
- GitHub・Bitbucket向けrepository provider routing
- サービスtokenの発行、ローテーション、失効、期限切れ削除
- Build、Release作成・公開・取り下げ、DeployのProvider委譲
- stateless Streamable HTTP MCP endpoint
- JSON入出力のWindows CLI
- アプリケーショングローバル例外処理
- MCPの日本語・英語エラーダイアログ
- WiX ToolsetベースのWindows x64 MSI

## 動作確認

- MSIの`C:\Moyai`への新規インストールと再インストール
- SQLiteデータの再インストール前後での保持
- CLIのバージョン表示と構造化エラー出力
- MCPのループバック待受と`/mcp` endpoint
- GitHub Actionsによるビルド、テスト、MSI作成

## 制限事項

- Windows x64のみを配布対象とします。
- MCPサーバーの待受はループバックに限定されます。
- Windowsサービスへの登録や自動起動は行いません。
- 実際のrepository、build、release、deploy操作には対応Providerの起動と設定が必要です。
