# Moyai icon

The Moyai icon depicts a rope knot with three crossings and two free ends, drawn with thick black lines on a transparent background. It is a knot symbol rather than an instructional diagram for a specific knot.

## Variants

| Use | Appearance | Files |
| --- | --- | --- |
| Application icon (48 px and larger) | Thick black outline with white rope interiors | `out/moyai.svg`, `out/moyai_*.png` |
| Notification area and small sizes (32 px and smaller) | Same black outline and white fill as the application | `out/moyai_tray.svg`, `out/moyai_tray_*.png` |
| Dark taskbar | Same black outline and white fill | `out/moyai_tray_white.svg`, `out/moyai_tray_white_*.png` |

All sizes share a thick black outline, white rope interiors, and a transparent background. Shorter rope ends keep the focus on the knot.

ICO files:

- `out/moyai.ico`: 16, 24, 32, 48, 64, 128 and 256 px
- `out/moyai_tray.ico`, `out/moyai_tray_white.ico`: 16, 20, 24 and 32 px

## Where the product uses it

The three ICO files are copied to `src/Moyai.Tray/Assets/`.

- `moyai.ico`: the `Moyai.Tray.exe` icon, window title bars, and the installed-programs list (`ARPPRODUCTICON` in `installer/Moyai.wxs`)
- `moyai_tray.ico` / `moyai_tray_white.ico`: the notification-area icons. Both light and dark variants use a black outline and white fill; the existing theme-specific filenames are retained.

## Regenerating

Requires Python 3 with Pillow and NumPy.

```powershell
python docs\design\icon\make_icon.py
```

This regenerates `docs\design\icon\out\`. To update the product, copy `moyai.ico`, `moyai_tray.ico` and `moyai_tray_white.ico` from `out\` to `src\Moyai.Tray\Assets\`.

The shape is generated by `knot_rope()` in `make_icon.py` and shared by `ROPE` (application icon) and `TRAY_ROPES` (small sizes). The third value of each point is the stacking order; higher values pass over lower ones.
